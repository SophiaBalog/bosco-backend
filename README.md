# Django Warehouse (Практична робота: Валідація та форми)

## Таблиця рівнів валідації

| Правило | Рівень | Чому саме тут |
| :--- | :--- | :--- |
| **Префікс артикула (`ART-`)** | Поле (`validators.py`) | Перевіряє формат окремого значення на рівні поля незалежно від інших даних. |
| **Максимум слів у назві** | Поле (`validators.py`) | Обмежує довжину тексту за допомогою параметризованого класу-валідатора. |
| **Рік випуску не з майбутнього** | Поле (`validators.py`) | Перевіряє логічну коректність дати відносно поточного системного року. |
| **Нормалізація назви та артикула** | Форма (`clean_<field>`) | Форма приводить введені дані до єдиного стандарту (регістр, пробіли) перед збереженням. |
| **Ціна зі знижкою менша за звичайну** | Форма та Модель (`clean`) | Крос-польове правило (потребує порівняння двох полів одночасно). На рівні форми виводить помилку біля потрібного поля через `add_error()`, а на рівні моделі захищає бізнес-логіку поза формами. |
